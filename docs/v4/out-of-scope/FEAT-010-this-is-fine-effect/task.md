# v4 / FEAT-010: "This is fine" fire effect

**Status:** planned. **Source:** [v4 out of scope](../README.md).

See [implementation plan](plan.md) and [acceptance criteria](acceptance.md).

## Previous behavior

- drawEM ships 16 built-in Lottie effects, all downloaded from LottieFiles
  ([ADR 0001](../../../adr/0001-lottie-built-in-effects.md),
  [sources](../../../../src/DrawEM.App/Presentation/Effects/BuiltIn/SOURCES.md)).
- No effect shows fire.

## Required behavior

A new built-in effect: flat cartoon fire along the bottom edge of the monitor,
in the style of the "This is fine" meme. Only the fire is drawn. The meme's
artwork (the dog, the room) belongs to KC Green and is not reproduced.

### Catalog entry

| Field | Value |
|---|---|
| Effect ID | `this-is-fine` |
| Name | `This is fine` |
| File | `this-is-fine.json` |
| Placement | Monitor |

### Animation

| Property | Value |
|---|---|
| Canvas | 3840×1080 (32:9) |
| Tallest flame | 20% of the canvas height (216 px) |
| Shortest flame | about 8% of the canvas height (86 px) |
| Flames | 6–10 tongues across the full width; the fire looks the same along the whole width |
| Motion | each tongue morphs its Bézier path through 3–4 keyframes, with a phase offset per tongue |
| Colors | outer `#E8461E`, middle `#F7931E`, core `#FFD23F`; opaque, no gradients |
| Smoke | none |
| Length | 2 s, 60 fps |
| Loop | seamless: the last frame equals frame 0; no intro, so Loop repeats without a visible restart |
| Background | transparent everywhere outside the flames |

Why 32:9: Monitor effects use cover scaling (`EffectCanvasPlacement.Cover`).
When the canvas is wider than the monitor, the scale follows the height, so the
full canvas height stays visible and only the sides are cropped. This holds for
every monitor from 32:9 to portrait. On such monitors the fire reaches 20% of
the monitor height and always touches the bottom edge. A monitor wider than
32:9 crops the top and bottom; that case is not supported.

### Generator

- The JSON file is generated by a C# console project,
  `tools/ThisIsFineEffect/`, next to `tools/RenderLagHarness/`.
- The parameters above are constants at the top of `Program.cs`.
- `dotnet run --project tools/ThisIsFineEffect` writes
  `src/DrawEM.App/Presentation/Effects/BuiltIn/this-is-fine.json`.
- The output is deterministic: a fixed random seed, so the same parameters
  produce the same file byte for byte.

### Licensing

`SOURCES.md` lists the file as own work of the drawEM project, generated by
`tools/ThisIsFineEffect`, not a LottieFiles download. The intro paragraph of
`SOURCES.md` changes so it no longer says that every file comes from
LottieFiles.
