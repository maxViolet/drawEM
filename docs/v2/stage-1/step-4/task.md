# Stage 1 / Step 4: publish and verify

**Status:** proposed. **Source:** [Stage 1 roadmap](../../ROADMAP-v2.md#4-publish-and-verify).

## Task

Wire the sound channel into startup and exit, build the self-contained Windows x64 app, and verify it on the user's desktop. Confirm audible WAV/MP3 playback, replacement, restart, completion, ten-second cutoff, failure handling, drawing independence, input blocking, multi-monitor behavior, and exit cleanup. Repeat the [v1 drawing smoke test](../../../v1/SMOKE-TEST.md). Record automated and manual evidence separately.

**Depends on:** [Steps 1–3](../../STAGE-1-SOUND-IMPLEMENTATION-PLAN.md).

See [plan](plan.md) and [acceptance criteria](acceptance.md).
