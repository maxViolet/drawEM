# Экранные действия: черновик архитектуры

**Статус:** обсуждается. Этот документ описывает будущую архитектуру; текущая реализация рисования описана в [ARCHITECTURE.md](ARCHITECTURE.md).

## Режим экранов

```text
GLOBAL_SCREEN_MODE = SINGLE_SCREEN
MULTIPLE_SCREEN = TODO
```

Все правила ниже относятся только к `SINGLE_SCREEN`. Поведение `MULTIPLE_SCREEN`, включая переход курсора между мониторами, ещё не определено.

В `SINGLE_SCREEN` активный экран — монитор, на котором находится курсор. При переходе курсора на другой монитор все активные действия каналов прерываются. Сохранённые рисунки на остальных мониторах остаются. Новое действие запускается на мониторе с курсором в момент нажатия комбинации.

## Каналы и действия

Для каждого монитора существует по одному каналу рисования, видео, звука и спецэффектов. Каждый канал допускает не более одного активного действия. Новое видео прерывает предыдущее видео; новый звук прерывает предыдущий звук. Звук внутри видео и отдельный звуковой канал могут воспроизводиться одновременно. Спецэффект имеет отдельный канал и может идти поверх видео.

Рисование активно при удержании назначенной комбинации. При переходе курсора на другой монитор оно прерывается; для нового штриха нужно отпустить комбинацию и нажать её снова. Очистка рисунка затрагивает только монитор с курсором и не удаляет рисунки на других мониторах.

## Комбинации и UI

Есть десять заранее заданных комбинаций: `Ctrl+Alt+Z`, `Ctrl+Alt+X` и `Ctrl+Alt+1`…`Ctrl+Alt+8`. Через UI каждой назначается одна команда; сами комбинации в UI не меняются. По умолчанию `Ctrl+Alt+Z` запускает рисование, а `Ctrl+Alt+X` очищает рисунок. Оба назначения можно изменить. Рисование и очистка представлены одной опцией «Рисование» с двумя командами и занимают два слота, когда обе назначены.

Видео, звуки и спецэффекты запускаются один раз при нажатии комбинации; удержание не вызывает повторного запуска. Через UI можно добавлять звуки и видео; при добавлении приложение копирует файл в свою библиотеку. Спецэффекты реализуются в коде и доступны в UI для назначения. Кнопка `Sample` запускает выбранный звук, видео или спецэффект без комбинации клавиш. Видео и спецэффект при таком запуске показываются на весь монитор с курсором, как и при горячей клавише.

Библиотека медиафайлов и назначения клавиш хранятся в профиле текущего пользователя Windows, отдельно от папки с исполняемым файлом.
