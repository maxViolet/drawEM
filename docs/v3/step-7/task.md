# v3 / Step 7: Settings window

**Status:** planned. **Source:** [v3 roadmap](../ROADMAP-v3.md#delivery-order).

## Task

Open Settings from the tray. Add Drawing and Actions tabs with a draft that
does not affect the active configuration until Save. Provide Save, Cancel,
and Restore defaults. Show validation and file errors. Allow selecting WAV/MP3
for eight numbered sound slots and sampling the selected draft file through
the global sound channel without changing active shortcuts.

**Depends on:** [Step 4](../step-4/task.md) and [Step 6](../step-6/task.md). **Enables:** [Step 8](../step-8/task.md).

See [plan](plan.md) and [acceptance criteria](acceptance.md).
