# v3 / Step 2: managed sound library

**Status:** implemented; see [acceptance](acceptance.md). **Source:** [v3 roadmap](../ROADMAP-v3.md#delivery-order).

## Task

Copy selected WAV/MP3 files into a managed library in the current user's
profile. A draft may select and share a copy without changing saved settings.
Cancel discards draft imports; successful Save retires copies with no saved
references. Startup removes orphaned copies only after settings load
successfully. Never move or delete the user's source file.

**Depends on:** [Step 1](../step-1/task.md). **Enables:** [Step 6](../step-6/task.md) and [Step 7](../step-7/task.md).

See [plan](plan.md) and [acceptance criteria](acceptance.md).
