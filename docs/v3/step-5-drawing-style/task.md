# v3 / Step 5: configurable drawing style

**Status:** implemented; see [acceptance](acceptance.md). **Source:** [v3 roadmap](../ROADMAP-v3.md#delivery-order).

## Task

Use the configured HEX color and integer width for each new stroke. Width is
measured in physical pixels on that stroke's monitor, for both lines and
single-point dots. The default becomes 4 physical pixels; on a 150% display
this is visibly thinner than the current 4 DIP stroke.

**Depends on:** [Step 1](../step-1-settings/task.md). **Enables:** [Step 6](../step-6-runtime-settings/task.md).
