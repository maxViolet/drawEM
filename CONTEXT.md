# Язык drawEM

drawEM запускает действия с помощью глобальных комбинаций клавиш и показывает результат поверх рабочего стола.

## Термины

**Действие**:
Выбираемая в UI опция: рисование, конкретное видео, конкретный экранный спецэффект или конкретный звук. Рисование включает две команды: рисовать при удержании и очистить рисунок.

**Команда**:
Конкретная операция действия, запускаемая одной комбинацией клавиш. Для рисования нужны две разные команды и две комбинации.

**Привязка клавиш**:
Соответствие одной комбинации клавиш одной команде. Одна комбинация не запускает несколько команд одновременно.

**Слот комбинации**:
Одно из десяти заранее заданных сочетаний клавиш, которому пользователь через UI назначает команду. Само сочетание через UI не меняется. Рисование занимает два слота, когда назначены обе его команды.

**Предпросмотр**:
Запуск выбранного звука, видео или спецэффекта для проверки без использования комбинации клавиш.
