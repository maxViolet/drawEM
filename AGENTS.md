# Правила для drawEM

## Общение

- Не общайся комплиментарно.
- На старте каждой сессии применяй навык `C:\Users\max\.codex\skills\i-have-adhd\SKILL.md` до команды `stop adhd mode` или `normal mode`.

## Названия веток для PR

- При создании ветки используй формат `<префикс>-<краткое-описание>`.
- Допустимые префиксы:
  - `DOC` — изменения документации.
  - `FEAT` — новая функциональность.
  - `FIX` — исправление ошибки.
  - Идентификатор задачи из документации — работа по конкретной задаче, например `S1-02`.
- Если работа соответствует задаче из документации, используй её точный идентификатор как префикс.
- Описание пиши на английском в нижнем регистре, разделяя слова дефисами.
- После `DOC`, `FEAT` или `FIX` можно добавить номер: например `DOC-007-branch-naming`.
- Примеры: `DOC-branch-naming`, `FEAT-sound-shortcuts`, `FIX-player-cleanup`, `S1-02-sound-channel`.
- Перед созданием ветки проверь имя по этим правилам. Существующие ветки переименовывай только по явному запросу пользователя.
